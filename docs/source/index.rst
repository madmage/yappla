==================================================================
YAPPLA - Yet Another Probabilistic Planning and Logic Architecture
==================================================================

YAPPLA is a lightweight, pure Python automated planning library implementing Dijkstra's algorithm in the state space. It supports deterministic and durative actions, with optional integration to the `Unified Planning <https://github.com/aiplan4eu/unified-planning>`_ library.
